# Энергоконтур — ИИ находит потери энергии, люди подтверждают экономию

Прототип для конкурса КМГ «Лучшие инновационные идеи и практики в области охраны здоровья, труда и окружающей среды». ИИ сравнивает расход энергии с моделью при том же выпуске и показывает перерасход; бригада устраняет утечку по допуску; энергетик принимает замер за 30 суток; финансист переводит подтверждённые кВт·ч в тенге.

**Все данные синтетические:** контуры, суточные ряды, решения и сценарий экономики вымышлены. Факты КМГ (87 мероприятий, 1,935 млн ГДж экономии за 2025 год) — из открытого отчёта.

## Что внутри MVP

- **Обзор** — принятые кВт·ч и тенге, очередь решений, тепловая полоса перерасхода по суткам.
- **Контуры** — три учебных случая: EC-01 «Технический воздух» (экономия принимается), EC-02 «Ниже выпуск» (ложный вывод, экономии нет), EC-03 «Неполный учёт» (приёмка заблокирована). Маршрут из 4 шагов, проверки энергетика, тариф, журнал.
- **Экономика** — сценарий одного ДЗО: 1/3/5 %, редактируемые допущения, покрытие запуска, CO₂.
- **Перенос в ДЗО**, **Журнал решений** (выгрузка JSON, «Начать заново»), **Источники и контроль ИИ**.

## Сборка

```bash
node build.js
```

Собирает `src/` в один файл `energokontur.html` и `public/index.html`, презентацию — в `presentation/index.html` и `public/presentation/`. Нужен только Node.js 18+, зависимостей нет. Для разработки: `node serve.js` → http://localhost:8791/

- `src/data.js` — синтетические данные (суммы проверяются `console.assert`);
- `src/charts.js` — SVG-графики; `src/app.js` — маршрут приёмки, экраны, журнал;
- `src/style.css`, `src/template.html`; шрифт Manrope — `assets/fonts/`.

## Презентация, видео, письмо

- `presentation/deck.src.html` — 7 слайдов; `node presentation/standalone.mjs` → `mail/Energokontur-prezentaciya.html` (один файл для почты: шрифты, логотип, MVP и оба ролика внутри).
- `video/idea`, `video/guide` — сценарии озвучки (`vo_script.json`, голос Microsoft Дмитрий через edge-tts), запись MVP (`guide/capture.mjs`), генераторы композиций Hyperframes (`gen.mjs`).

## Хостинг

Render → New → Static Site → этот репозиторий. Build Command: `node build.js`, Publish Directory: `public`. Переменные окружения не нужны (или New → Blueprint по `render.yaml`).
